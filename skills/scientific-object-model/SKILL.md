# Scientific Object Model

Use the backend object schema and project-scoped API. Scientific objects form a parent/child tree; relations are separate typed edges. Validate parent ownership before creating a child and preserve stable IDs.

Do not invent biological ontology tables or duplicate server enums in agent text.
