# ADR-0001: Independent Product And Repository

## Context
REvoLab is the scientific context layer, distinct from REvoCompute execution and REvoDesign interactive design.

## Decision
Keep REvoLab as a standalone repository and architectural domain.

## Consequences
Ownership and release boundaries stay clear; integrations use explicit contracts.

## Rejected alternatives
Implementing REvoLab as a REvoCompute Project extension or modifying sibling repositories.
