# Third-Party Architecture References

REvoLab is distributed under Apache-2.0. The repositories listed below informed architecture decisions only; their implementation source was not copied or vendored into this repository.

- LaminDB, AiiDA, OpenLineage
- fsspec, pluggy, Cordis
- BenchOS, eLabFTW, Renku
- OpenBio Skills, Galaxy Foundry

BenchOS, eLabFTW, and the OpenBio Skills repository have licensing or notice considerations that make source reuse inappropriate for this bootstrap. REvoLab uses independently written code and records concepts in `docs/architecture/reference-study.md`. Dependencies will be selected and audited separately before adoption.
